# GitHub Actions Secrets Configuration

# These must be set in GitHub Repository:
# Settings → Secrets and variables → Actions

# 1. CLOUDFLARE_API_TOKEN
#    - Your Cloudflare API token with R2 permissions
#    - Generate at: https://dash.cloudflare.com/profile/api-tokens
#    - Scopes: Account > R2 Full Access

# 2. NETLIFY_AUTH_TOKEN
#    - Your Netlify authentication token
#    - Generate at: https://app.netlify.com/user/settings/tokens
#    - Keep secret - never share

# 3. NETLIFY_SITE_ID
#    - Your Netlify site ID (number)
#    - Find at: https://app.netlify.com/sites/your-site/settings/general
#    - Example: 1234567890abcdef

# 4. GITHUB_TOKEN (auto-generated by GitHub Actions)
#    - No need to set - provided automatically
#    - Used for repository operations

# 5. VITE_GEMINI_API_KEY (also set in .env.local)
#    - Google AI Studio key
#    - Get at: https://aistudio.google.com/apikey

# 6. VITE_FIREBASE_API_KEY (for Vibe DAW)
#    - Firebase project API key
#    - Get from: Firebase Console → Project Settings → General

# GitHub Actions workflow example:
# - Name: Deploy Cloudflare
# - Uses: CLOUDFLARE_API_TOKEN secret
# - Name: Deploy Netlify
# - Uses: NETLIFY_AUTH_TOKEN + NETLIFY_SITE_ID secrets

echo "✅ GitHub Actions secrets configuration documented"
